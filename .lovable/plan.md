# Clone Visual Halaman Publik dari Situs Referensi

## Tujuan
Menyamakan seluruh halaman publik aplikasi dengan https://butonselatan11.narmanportofolio.site secara visual, sambil mempertahankan data, fungsi, autentikasi, dan izin akses yang sudah berjalan.

## Langkah
1. Inventarisasi semua rute publik serta pola visual situs referensi pada desktop dan ponsel.
2. Bandingkan komponen bersama, token warna, tipografi, header, footer, dan setiap pola halaman terhadap proyek saat ini.
3. Terapkan perbedaan pada komponen dan halaman publik tanpa menyentuh proses bisnis atau halaman internal.
4. Uji rute publik representatif pada desktop dan ponsel, termasuk navigasi, formulir, keadaan kosong, dan detail dinamis.

## Batasan
- Situs referensi menjadi sumber kebenaran visual.
- Data dan isi dinamis tetap berasal dari Lovable Cloud proyek ini.
- Dashboard, otorisasi, dan alur internal tidak diubah.
- Jika data referensi berbeda, struktur dan gaya disamakan tanpa menyalin data pengguna.

## Validasi
- Tidak ada error kompilasi atau error browser.
- Header, footer, warna, ukuran, jarak, kartu, dan susunan konten sesuai referensi.
- Semua rute publik tetap berfungsi pada desktop dan ponsel.
